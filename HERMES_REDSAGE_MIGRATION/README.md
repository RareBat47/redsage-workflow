# Hermes + RedSage Linux migration package

When cloned from the private migration repository, start with [`NEW_HERMES_INITIALIZATION_PROMPT.md`](NEW_HERMES_INITIALIZATION_PROMPT.md), then continue with [`RESTORE_PROMPT.md`](RESTORE_PROMPT.md). When using the standalone ZIP, `RESTORE_PROMPT.md` remains the authoritative package-level restore instruction. Read `migration/MANIFEST.md`, `migration/MIGRATION.md`, `migration/WINDOWS_TO_LINUX.md`, and `SECRETS_REQUIRED.md` before changing anything.

This package was built locally from the Windows installation. It excludes secrets, Windows virtual environments, executables, caches, node_modules, and temporary runtime files. It has not been uploaded anywhere.

`RESTORE_PROMPT.md` is the authoritative starting instruction for a brand-new Hermes installation on Linux. Read it first, then follow the inspection-first process it defines.
